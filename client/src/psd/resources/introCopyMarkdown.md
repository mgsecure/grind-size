You can experiment with this beta version using a number of demos by clicking on the **[Choose Dataset](/psd?sampleSet=a92951f6)** button below. 

If you'd like to try out the full pipeline you can download and print the [Photo Templates](/templates/coffee-grind.com_PSD_templates_v02.pdf) that the PSD tool uses to extract the grind data. You can then take photos of your own grinds and use the PSD to analyze them. If you just want to see a bit more of how the tool works, you can download some of the [Original Grind Images](/data/Kinu_M47_POB_0-4_Compare_Images.zip) used for the demo above.
